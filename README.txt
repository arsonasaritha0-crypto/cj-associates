CJ ASSOCIATES WEBSITE — QUICK START

FILES
- index.html: website content
- styles.css: design, colours and responsive layout
- script.js: mobile navigation and enquiry form

PREVIEW ON YOUR COMPUTER
1. Keep all three files in the same folder.
2. Double-click index.html to open it in your browser.
3. Internet access is needed for the Google Fonts; the site still works without them.

BEFORE PUBLISHING
1. Open script.js in a text editor.
2. Replace YOUR_EMAIL@example.com with the business email that should receive enquiries.
3. Replace the concept illustrations in the portfolio with your own authorised project images when ready.
4. Check all text and services and only make claims you can support.
5. Test the contact form. It opens the visitor's email app; it does not store submissions or send mail directly from the website.

FREE PUBLISHING OPTION: GITHUB PAGES
1. Create an account at https://github.com/
2. Create a new public repository, for example cj-associates-site.
3. Upload index.html, styles.css and script.js to the repository's root.
4. Open repository Settings → Pages.
5. Under Build and deployment, select Deploy from a branch; choose main and / (root), then Save.
6. Wait for GitHub Pages to publish. The public site address will be shown in the Pages settings.
7. After editing files, upload the updated versions to the same repository.

IMPORTANT
- This is a static website starter, not yet published online.
- The sample visual panels are illustrative concept graphics, not real completed projects.
- A contact form that sends directly without opening an email app needs a form service or a backend.
- Do not publish private client details or project images without permission.
